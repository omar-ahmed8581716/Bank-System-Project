# Bank Management System (C++)

A C++ console application designed to manage client bank accounts and perform financial transactions with local file persistence.

 Features

- Client Management : Show client list, add new clients, search by account number, update info, and delete clients.
- Transactions : Deposit, withdraw (with balance validation), and display total balances.
- File Persistence : Saves and loads all client data automatically to "DataInfo.txt".

 Concepts Used

- Procedural Programming : Functions and structured logic.
- Data Structures : `std::vector` and `struct`.
- File Handling : `fstream` for text file operations.
- Input Validation & String Parsing.
